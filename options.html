Real Black Mode setup

Why a .bat? Firefox blocks extensions from changing the prefs below at the plugin level — there's no WebExtension API for browser.display.* / browser.anchor_color. It's technically possible with an external native-messaging host (a small Python or Go helper), but that would require installing a second program. A one-shot .bat keeps the setup to a single file you can read and delete afterwards.

Don't want to run a .bat? You can skip it entirely — see Manual setup further down for the two ways to set these prefs by hand.

One-time step: download a script that writes these color prefs to your Firefox profile.

Manual setup (no .bat)

You don't have to run the .bat at all. Anything it does, you can do by hand — the two options below do the same thing, just with more clicking. Pick whichever you're comfortable with.

Open about:config, search for each name, and set the value. If a pref doesn't exist, click the + button, pick the type shown, and enter the value without quotes. Click any highlighted name or value below to copy it.

Pref nameTypeValue

Two ways to use these values — pick one:

1. user.js (recommended). Click Copy all as user.js lines below, open the profile folder path (use the second button to copy it, then paste into Explorer's address bar), create a file named user.js if it doesn't already exist, and paste the lines at the end. These prefs are reapplied every time Firefox starts, so they survive updates.

2. about:config (one-off). Paste each name and value directly into about:config using the + button. Simpler, but values can be reset by Firefox on updates. The path %APPDATA%\Mozilla\Firefox\Profiles is where user.js lives — copy it with the button below, then paste it into Explorer's address bar.
