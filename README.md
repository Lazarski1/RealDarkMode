# RealDarkMode
Real Dark Mode for Firefox. 
1. I used "Toggle Website Colors (Global)" by Manuel Reimer as a base. Source code: https://github.com/M-Reimer/toggleglobalcolors
2. It used a different way to toggle colors, I changed most of the script in that regard.
3. I used Claude and Deepseek for most of the coding. (I'm not a pro, was just a convienent way to do so)
4. If you want to customize colors or something, change the user.js . I have not found a way to do it from browser directly, if you know the way, please show me da way. 
5. Some sites/imbedded pictures/UI stuffs will be broken, it's not perfect, but it just works for now.
